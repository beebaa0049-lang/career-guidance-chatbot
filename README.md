# 🎓 CareerBuddy — AI Career Guidance Chatbot

**Task 4 — EncoderX AI/ML Internship (Batch 02)**
**Domain:** AI / ML | **Duration:** 1 Week

## 📌 Overview
An AI-powered career guidance chatbot built using Google Gemini.
The chatbot answers career, education, skills, resume and interview
related questions with a professionally engineered system prompt,
persona rules and topic guardrails.

## ✨ Features
- Prompt engineering (persona, structured responses, guardrails)
- Off-topic query redirection
- Career-specific conversational AI
- Publicly deployed and shareable

## 🛠️ Tech Stack
Google Gemini · Custom Gem (deployment) · Python reference implementation (app.py)

## 🧪 Testing
Tested on 20+ queries covering: response accuracy, conversation quality,
off-topic handling, and response time.

## 📚 Learnings
- Prompt engineering and conversation design
- LLM behavior control via system instructions
- Real-world API/SDK challenges and debugging
- Deploying AI tools for public use
